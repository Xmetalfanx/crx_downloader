# CRX Chrome Webstore downloader

The intent of this is to accept chrome store links and download crx files for the Chrome extension.

## Browser version compatibility

The downloader uses the current Chrome Stable release as its target version when retrieving extensions.

If your Chrome/Chromium-based browser is slightly behind the current release, the downloaded extension may still work. However, this is not guaranteed. An extension may require features that are only available in a newer version of Chrome.

If an extension does not work after downloading, one of the first things to check is whether your browser is up to date.

**In short:** being a version or two behind may be fine, but if you run into problems, make sure your browser is running the latest available version before troubleshooting further.
